Bases: BaseSQLSource

SQL-queryable xarray data source for Lumen.

Wraps xarray datasets with Apache DataFusion (via xarray-sql) to provide full SQL query support. Each data variable in the dataset is exposed as a separate SQL table with coordinate columns.

To use this source, install the optional xarray dependencies::

pip install lumen[xarray]
